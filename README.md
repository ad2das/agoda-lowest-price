# Agoda Always Lowest Price (아고다 최저가 도우미)

전 세계 아고다 숙소에서 **2인 유효 최저가**를 자동으로 찾아 하이라이트하고, 1클릭으로 예약까지 진행해주는 유저스크립트입니다.

- 한국어 / English / 日本語 페이지 모두 지원
- 일본뿐 아니라 모든 국가의 아고다 숙소에서 동작

## 기능

| 기능 | 설명 |
|---|---|
| 최저가 자동 탐지 | 페이지의 모든 객실 오퍼를 스캔해 2인 기준 유효 최저가를 찾음 |
| 1인실/인원초과 필터 | `성인 1명`, `1 Adult`, `大人1名`, `for 1 Person` 등 1인용 요금을 자동 제외 (가짜 최저가 방지) |
| 최저가 하이라이트 | 최저가 오퍼 셀을 초록 테두리 + `⬇ 최저가` 배지로 표시 |
| 최저가 자동 선택 | 최저가 방을 자동으로 클릭 (설정에서 끌 수 있음) |
| 1클릭 예약 | `🎯 최저가 바로 예약` 버튼 — 최저가 셀로 스크롤 후 예약 버튼 클릭 |
| 세금포함 총액 표시 | `1박당 요금`(세금포함) × 박수(`los`)로 총액 계산. 명시된 총액 우선, 없으면 국가별 세금 계수로 추정 |
| 쿠폰 자동시도 | 결제 페이지에서 프로모션 코드 목록을 자동으로 시도 (목록 편집 가능) |
| 가격 변동 감지 | 방문 중 가격이 내려가면 알림 + 관찰 최저가 기록 (localStorage) |
| 현지통화 경고 | 표시 통화가 숙소 국가 통화가 아니면 5% 수수료 위험 경고 |

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 확장 프로그램 설치 (Chrome/Edge/Firefox)
2. 아래 링크의 내용 복사:
   - https://raw.githubusercontent.com/ad2das/agoda-lowest-price/main/agoda-userscript.user.js
3. Tampermonkey 대시보드 → **새 스크립트** → 붙여넣기 → 저장 (Ctrl+S)
4. 아고다 호텔 페이지를 열면 우측 상단에 패널이 나타남

## 사용법

1. 아고다에서 숙소 + 날짜 + **성인 2명**으로 검색 → 호텔 페이지 진입
2. 패널이 자동으로 최저가(1박, 세전)와 총액(세금포함)을 표시
3. **`🎯 최저가 바로 예약`** 클릭 → 최저가 오퍼로 예약 진행
4. 결제 페이지에서 `🎟 쿠폰 지금 시도` → 쿠폰 자동 검색
5. 패널 우측 상단 `—` 버튼으로 접기, 헤더 드래그로 이동

### 패널 설정

- **최저가 하이라이트** — 초록 테두리/배지 표시 여부
- **최저가 방 자동선택** — 페이지 진입 시 최저가 방 자동 클릭 (기본 켜짐)
- **쿠폰 자동시도** — 결제 페이지에서 쿠폰 자동 시도 여부
- **가격변동 감지** — 관찰 최저가 기록 여부
- **쿠폰 목록 편집** — 시도할 쿠폰 코드 추가/삭제 (한 줄에 하나)

## 동작 원리

- 객실 오퍼 가격은 `[data-selenium="PriceDisplay"]` 요소에서 파싱
- 1인용 요금(예: 일본 호텔의 `1인 요금`)은 인원수 표시(`성인 1명`/`1 Adult`/`大人1名`)와 객실명(`for 1 Person`)으로 판별해 제외 — **2인 검색 기준으로 진짜 최저가만** 표시
- 세금포함 총액: 셀에 명시된 `1박당 요금`(per night) 값을 우선 사용 → 없으면 국가별 세금 계수(locale 기반, 예: 일본 26.5%)로 추정
- 가격은 아고다 서버가 내려주는 값을 그대로 사용 (임의로 조작하지 않음)

## 주의

- 가격은 아고다 서버 기준이며 할인(플래시딜 등)이 이미 적용된 값입니다
- 1인 1실 예약 시에는 1인 요금이 더 저렴할 수 있으나, 이 스크립트는 **2인 검색 기준**으로 동작합니다
- 쿠폰 코드는 호텔/계정/시기별로 적용 여부가 달라 항상 유효한 것은 아닙니다
- 비공식 유저스크립트입니다 — 아고다와 무관하며, 변경된 페이지 구조에 따라 수동 업데이트가 필요할 수 있습니다
