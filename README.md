# Agoda Always Lowest Price (아고다 최저가 도우미)

전 세계 아고다 숙소에서 **2인 유효 최저가**를 자동으로 찾아 하이라이트하고, 1클릭으로 예약까지 진행해주는 유저스크립트입니다.

- 한국어 / English / 日本語 페이지 모두 지원
- 일본뿐 아니라 모든 국가의 아고다 숙소에서 동작

## 기능

| 기능 | 설명 |
|---|---|
| 최저가 자동 탐지 | 페이지의 모든 객실 오퍼를 스캔해 2인 기준 유효 최저가를 찾음 |
| 저가 채널(cid) 자동 적용 | 알려진 CID + 7자리 전 범위 층화 표본 + 과거 승자/인접 CID를 최대 150개 비교하고, 최저 후보를 반복 검증한 뒤 자동 전환 (검색 조건별 30분 캐시) |
| 1인실/인원초과 필터 | `성인 1명`, `1 Adult`, `大人1名`, `for 1 Person` 등 1인용 요금을 자동 제외 (가짜 최저가 방지) |
| 최저가 하이라이트 | 최저가 오퍼 셀을 초록 테두리 + `⬇ 최저가` 배지로 표시 |
| 최저가 자동 선택 | 최저가 방을 자동으로 클릭 (설정에서 끌 수 있음) |
| 1클릭 예약 | `🎯 최저가 바로 예약` 버튼 — 최저가 셀로 스크롤 후 예약 버튼 클릭 |
| 세금포함 총액 표시 | `1박당 요금`(세금포함) × 박수(`los`)로 총액 계산. 명시된 총액 우선, 없으면 국가별 세금 계수로 추정 |
| 쿠폰 자동시도 | 결제 페이지에서 프로모션 코드 목록을 자동으로 시도 (목록 편집 가능) |
| 가격 변동 감지 | 방문 중 가격이 내려가면 알림 + 관찰 최저가 기록 (localStorage) |
| 현지통화 경고 | 표시 통화가 숙소 국가 통화가 아니면 5% 수수료 위험 경고 |

## 설치

1. Firefox에 Violentmonkey 설치 (Chrome/Edge는 Tampermonkey도 지원)
2. 아래 링크의 내용 복사:
   - https://raw.githubusercontent.com/ad2das/agoda-lowest-price/main/agoda-userscript.user.js
3. Violentmonkey 대시보드 → **새 스크립트** → 붙여넣기 → 저장 (Ctrl+S)
4. 아고다 호텔 페이지를 열면 우측 상단에 패널이 나타남

## 사용법

1. 아고다에서 숙소 + 날짜 + **성인 2명**으로 검색 → 호텔 페이지 진입
2. 패널이 자동으로 최저가(1박, 세전)와 총액(세금포함)을 표시
3. **`🎯 최저가 바로 예약`** 클릭 → 최저가 오퍼로 예약 진행
4. 결제 페이지에서 `🎟 쿠폰 지금 시도` → 쿠폰 자동 검색
5. 패널 우측 상단 `—` 버튼으로 접기, 헤더 드래그로 이동

### 패널 설정

- **최저가 하이라이트** — 초록 테두리/배지 표시 여부
- **최저가 방 자동선택** — 페이지 진입 시 최저가 방 자동 클릭 (기본 켜짐)
- **쿠폰 자동시도** — 결제 페이지에서 쿠폰 자동 시도 여부
- **가격변동 감지** — 관찰 최저가 기록 여부
- **저가 채널(cid) 자동적용** — 호텔 페이지 진입 시 채널(cid) 스캔 후 더 싼 채널로 자동 전환 (기본 켜짐, 끄면 원래 가격 유지)
- **CID 새 범위 검색** — 캐시를 지우고 이전과 다른 7자리 CID 표본으로 정밀 검색
- **쿠폰 목록 편집** — 시도할 쿠폰 코드 추가/삭제 (한 줄에 하나)

## 동작 원리

- 객실 오퍼 가격은 `[data-selenium="PriceDisplay"]` 요소에서 파싱
- 아고다는 URL의 `cid` 파라미터(파트너 채널 번호)에 따라 **같은 호텔·같은 날짜라도 가격이 다르게** 응답합니다. 스크립트는 현재 페이지의 최신 `room-grid` 요청을 그대로 복제해 결제 총액을 비교하고, 최신 API를 사용할 수 없을 때만 `GetSecondaryData`를 호환 경로로 사용합니다.
- CID 전체 목록은 공개되어 있지 않으므로 고정된 소수 번호만 검사하지 않습니다. 알려진 앵커, `1~9,999,999` 전 구간의 결정적 층화 표본, 페이지에서 발견한 CID, 과거에 최저였던 CID와 그 인접 번호를 합쳐 최대 150개를 검사합니다. 30분 뒤 또는 **CID 새 범위 검색**을 누르면 표본이 바뀌며, 발견한 승자는 이후 호텔 검색에도 재사용됩니다.
- 검색이 끝나면 현재 CID와 상위 최저 후보를 각각 2회 다시 조회해 평균 결제 총액을 비교합니다. 재검증에 실패하거나 가격이 흔들리면 자동 이동하지 않습니다.
- 캐시는 호텔 ID뿐 아니라 체크인·체크아웃·객실 수·인원·통화까지 구분하므로, 같은 도시의 다른 호텔이나 다른 날짜 결과가 섞이지 않습니다.
- 서버 부담과 일시 차단을 줄이기 위해 요청 간격·동시 요청 수를 제한합니다. 서버 오류가 연속되면 자동 중단하며, 잠시 뒤 **CID 새 범위 검색**으로 재시도할 수 있습니다.
- 채널별 가격 차이는 호텔과 검색 조건마다 다릅니다. 후보 가격이 모두 같으면 현재 URL을 그대로 유지합니다.
- 1인용 요금(예: 일본 호텔의 `1인 요금`)은 인원수 표시(`성인 1명`/`1 Adult`/`大人1名`)와 객실명(`for 1 Person`)으로 판별해 제외 — **2인 검색 기준으로 진짜 최저가만** 표시
- 세금포함 총액: 셀에 명시된 `1박당 요금`(per night) 값을 우선 사용 → 없으면 국가별 세금 계수(locale 기반, 예: 일본 26.5%)로 추정
- 가격은 아고다 서버가 내려주는 값을 그대로 사용 (임의로 조작하지 않음)

## 주의

- 가격은 아고다 서버 기준이며 할인(플래시딜 등)이 이미 적용된 값입니다
- 1인 1실 예약 시에는 1인 요금이 더 저렴할 수 있으나, 이 스크립트는 **2인 검색 기준**으로 동작합니다
- 쿠폰 코드는 호텔/계정/시기별로 적용 여부가 달라 항상 유효한 것은 아닙니다
- 비공식 유저스크립트입니다 — 아고다와 무관하며, 변경된 페이지 구조에 따라 수동 업데이트가 필요할 수 있습니다

- **v1.7.0** — Firefox/Violentmonkey용 CID 검색 완성: 최신 `room-grid` API 우선 + 기존 API 폴백, 실제 결제 총액 비교, 검색 조건별 캐시, 고정 동시성/요청 간격/서버 오류 조기 중단, 반복 리디렉션 방지, CID 수동 재검색 버튼 및 디버그 상태 API 추가
- **v1.6.0** — 저가 채널(cid) 자동 적용: 호텔별 채널 가격 스캔(약 100채널 백그라운드) → 더 싼 채널 발견 시 자동 전환, 호텔별 6시간 캐시. 실제 결제 금액 반영 검증 완료 (2박 ₩273,212 → ₩258,034, ~5.6% 절약). 신라호텔 등 채널 차이 없는 호텔은 유지. 헤드리스 E2E로 cid=48000 자동 전환 확인
- **v1.5.2** — Firefox/신형 레이아웃(a6d3f) 변형 최저가 탐색 버그 수정: 노이즈(조회수·리뷰·브레드크럼) 필터, 객실카드 지문 검증(`1박당`/`총액`), 가격이 안 잡히면 상단 고정바(StickyNav) 최저가 폴백. 헤드리스 Firefox·Chrome 양쪽에서 최저 ₩106,680 / 2박 ≈ ₩269,900 검증 완료
